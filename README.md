### 📌 Featured Project

#### 🔹 [ADM Premium](https://github.com/DheekeyCarey)
A web application with a Google Apps Script backend and a Blogger-themed frontend, featuring an experimental OMR-based answer sheet (LJK) scanning module — scanned directly via phone camera and processed in real time. The project also includes a desktop companion app built with Tauri (Windows/Linux/macOS) and a PWA build for iOS, deployed through GitHub Actions.
